בשביל שהשרת יוכל להתחבר למסד הנתונים, השתמשתי במשתני סביבה (.env).
מכיוון שהעליתי את הפרויקט לגיטהב כפרויקט פומבי, לא צירפתי את הקובץ המקורי עם הסיסמה שלי.
כדי להפעיל את ה-Backend:
כנסו לתיקיית server (שם נמצא הקוד של השרת וה-API).
יצרתי קובץ שנקרא .env.example.
העתיקו את התוכן שלו לקובץ חדש שתפתחו בשם .env.
בתוך הקובץ החדש, תכתבו את הסיסמא של מאגר הנתונים שלכם ואת שאר הפרטים
(השארתי שם את הדיפולט של המאגר שיצרתי, hadasim_trip).
תריצו npm install כדי להתקין את כל הספריות שהשתמשתי בהן (כמו mysql2 ו-dotenv).
כדי להפעיל את השרת, תכתבו בטרמינל npm run dev. 
השרת אמור לרוץ על פורט 5000, אלא אם תשנו אותו ב-.env.
הגדרת מסד הנתונים:
לפני שמריצים את השרת, צריך לוודא שיצרתם מאגר עם הטבלאות המתאימות בשם hadasim_trip 
(הוספתי את הפקודות בתיקיית ה-database).
הנחות:
*הנחתי שמספרי תעודת הזהות שמוזנים הם תקינים.
*הנחתי שמי שמבצע את הרישום מזין שם כיתה תקין וזהה גם למורה וגם לתלמידות שלה. 
*בניתי את מסד הנתונים ככה שהקשר בין מורה לתלמידה הוא לפי שם הכיתה. בחרתי בזה כי ככה המערכת גמישה – אם מורה מחליפה כיתה או אם יש כמה מורות לאותה כיתה בטיול, הן תמיד יוכלו לשלוף את רשימת התלמידות המעודכנת בלי שצריך לשנות את כל הקוד.

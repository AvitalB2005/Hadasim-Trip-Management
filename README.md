בשביל שהשרת יוכל להתחבר למסד הנתונים, השתמשתי במשתני סביבה (.env).
מכיוון שהעליתי את הפרויקט לגיטהב כפרויקט פומבי, לא צירפתי את הקובץ המקורי עם הסיסמאות שלי.

## Backend (שרת)
כנסו לתיקיית `server` (שם נמצא הקוד של השרת וה-API).
יצרתי קובץ שנקרא `.env.example`.
העתיקו את התוכן שלו לקובץ חדש שתפתחו בשם `.env`.
בתוך הקובץ החדש, תכתבו את הסיסמא של מאגר הנתונים שלכם ואת שאר הפרטים
(השארתי שם את הדיפולט של המאגר שיצרתי, hadasim_trip).
סיסמת המורה לרישום (קוד אימות): manager_trip_2026
תריצו `npm install` כדי להתקין את כל הספריות.
כדי להפעיל את השרת: `npm run dev` (nodemon).
השרת אמור לרוץ על פורט 5000, אלא אם תשנו אותו ב-`.env`.

## Frontend (React + Vite)
בתיקיית `client`:
1. העתיקו `client/.env.example` לקובץ `client/.env` ועדכנו אם צריך את `VITE_API_URL` (ברירת מחדל: `http://localhost:5000`).
2. `npm install`
3. `npm run dev` — הלקוח יפתח בדרך כלל על פורט 5173.

ניווט בלקוח: כניסה ל־`/` מפנה אוטומטית ל־`/register`. התחברות מורה: `/login`. דשבורד: `/dashboard`. הסברים בעברית לעצמי: תיקיית `client/docs/`.

## מסד הנתונים
לפני שמריצים את השרת, צריך לוודא שיצרתם מאגר עם הטבלאות המתאימות בשם hadasim_trip
(הפקודות בתיקיית `server/database`).
חשוב: בטבלת `Classes` צריכות להיות שורות כדי שהרשימה הנפתחת בהרשמה לא תהיה ריקה.
